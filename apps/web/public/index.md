# Art by John Philip Morgan

Art is John Philip Morgan's personal catalog for discovering and saving physical artworks, artists, galleries, and styles.

## Browse the catalog

- [Artists](https://art.jpamorgan.com/artists.md)
- [Galleries](https://art.jpamorgan.com/galleries.md)
- [Styles](https://art.jpamorgan.com/styles.md)

The public catalog can be explored without an account. Personal favorites, follows, and the For You feed require an interactive browser login.

## Agent access

Agents should begin with the [agent guide](https://art.jpamorgan.com/llms.txt), then use the read-only MCP server declared in the [MCP server card](https://art.jpamorgan.com/.well-known/mcp/server-card.json) or the A2A v1.0 interface declared in the [A2A Agent Card](https://art.jpamorgan.com/.well-known/agent-card.json). Machine-readable discovery is available through the [AI catalog](https://art.jpamorgan.com/.well-known/ai-catalog.json), [Agent Skills index](https://art.jpamorgan.com/.well-known/agent-skills/index.json), and [agent authentication guide](https://art.jpamorgan.com/auth.md).

Source code and agent contribution instructions are public in the [art-curator repository](https://github.com/jpamorgan/art-curator) and its [AGENTS.md](https://github.com/jpamorgan/art-curator/blob/main/AGENTS.md).
